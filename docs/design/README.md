# Макеты (docs/design)

Здесь агент `ui-designer` складывает варианты интерфейса для обсуждения до разработки.

Структура: `docs/design/<фича>/variant-a.html`, `variant-b.html`. Это самодостаточные HTML-файлы: откройте двойным кликом в браузере. Это **наброски**, а не финальный дизайн; выбранный вариант фиксируется в спеке (`docs/specs/<фича>.md`, раздел «Макеты / UX»).
