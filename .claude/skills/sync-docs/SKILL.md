# /sync-docs — актуализация документации

Область: **$ARGUMENTS** (по умолчанию — всё затронутое веткой).

1. Определи, что изменилось: `git diff main...HEAD --stat` (и незакоммиченное).
2. Найди связанные документы: `docs/specs/`, `docs/adr/`, `docs/architecture/`, `docs/api/`, `docs/frontend/`, `README.md`, `CLAUDE.md`, `backend/CLAUDE.md`, `frontend/AGENTS.md`.
3. Для каждого: соответствует ли описанное коду (команды, пути, поведение, архитектурные правила)? Проверяй по коду, не по памяти.
4. Составь список расхождений: документ → что устарело → что верно (с путём к коду).
5. Делегируй правки агенту `tech-writer` (для спек — `product-analyst`). Новое архитектурное решение без ADR — предложи `/new-adr`.
6. Выведи: что обновлено, что осталось открытым (`TODO(вопрос)`).
